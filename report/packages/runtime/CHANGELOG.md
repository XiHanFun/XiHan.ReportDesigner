# @xihan-report/runtime

## 1.0.0-rc.1

### Major Changes

- f2bd216: **新增** 首次发布，以原生 Web Components 交付，不绑定前端框架。

  - `@xihan-report/core`：报表定义的结构（数据集与字段、计算字段、报表参数，主体是明细表、分组报表、交叉表或看板与卡片，卡片之间的联动）、校验与问题码、按参数与联动选中算出取数请求、按取回的明细行或汇总行计算视图与卡片（聚合、透视、排序、公式度量）、编辑操作与撤销重做、卡片与视图种类的登记与扩展合并。纯 TypeScript，不依赖 DOM。
  - `@xihan-report/runtime`：`<xh-report-viewer>` 按报表定义与取数回调计算并显示明细表、分组报表、交叉表与看板，带参数栏、卡片联动与表格下钻事件；`export('xlsx')` 把当前的计算结果写成 Excel 工作簿，`@xihan-report/runtime/xlsx` 把视图排成工作表；与 XiHan.UI 内建语言一一对应的界面语言包（`@xihan-report/runtime/locale`），查看器与设计器共用。
  - `@xihan-report/designer`：`<xh-report-designer>` 可视化设计器，包括菜单栏（文件、编辑、视图、数据、帮助）与工具栏、数据集与报表参数面板、物料、看板卡片的框选拖动与改大小、画布缩放与拖动工具、字段栏（拖进字段、换序、交叉表透视）、属性面板、问题列表、预览、撤销重做与剪贴板。面板能换栏、调先后、收起与浮出，布局存进设置；另有页面结构（能多选）与历史记录两块面板、选中卡片时的选中工具条与尺寸徽标。设置对话框有基础（主题、主题色、状态栏、自动保存、开发者模式与调试日志）、语言、布局、工具栏几页，以及帮助、快捷键与关于；选定的语言只作用于设计器。数据集、字段与报表参数能从 JSON 样例或 JSON Schema 导入；开发者模式下整份报表定义能在对话框里按 JSON 编辑，应用后能撤销。按 `draftKey` 在本机自动保存草稿，再装进同一份报表时问恢复还是丢弃。第一次打开时有一段新手引导。宿主的模板标题与保存状态能放进菜单栏正中与状态栏右端。卡片与视图种类、渲染、导出器、取数中间件、属性编辑器、命令、面板、物料、物料来源、导入器（登记了才有「导入模板」）、菜单栏的菜单与设置分区都能经 `extensions` 登记。

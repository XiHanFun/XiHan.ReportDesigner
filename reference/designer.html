设计器 ​

@xihan-report/designer 的公开接口。样式在 @xihan-report/designer/style.css，还要同时引入 @xihan-ui/designer-shell/style.css 与 @xihan-report/runtime/style.css。

<xh-report-designer> ​

注册 <xh-report-designer> 与它用到的查看器、UI 元素与 designer-shell 零件；import 时不注册。

属性 ​

属性attribute类型说明
schema—ReportDocument | undefined报表定义：赋值即装载（清空历史与选择）；赋回当前这一份不重新装载。读取得到当前报表。
dataProvider—ReportDataProvider | undefined与查看器同一个取数回调，画布与预览用；不给时画布画占位。
expressionEngine—ExpressionEngine | undefined表达式引擎：计算字段与公式度量要用，校验公式也用它。
formatter—ReportFormatter | undefined值的显示文字；缺省按格式说明调 formatValue。
parameters—ParameterValues | undefined预览与画布取数用的报表参数取值。
commandLayout—DesignerCommandLayout | undefined工具栏、菜单栏的各张菜单（menubar:file、menubar:edit、menubar:view、menubar:data、menubar:help）、右键菜单（menu:card、menu:blank）与选中工具条（selection:card、selection:multiple）的命令排列；写了某个位置就只显示列出的命令。
translations—Partial<ReportDesignerTranslations> | undefined元素自己的文案，压在全局配置之上。
localelocalestring | undefinedBCP 47 语言标记；缺省取全局配置。
timeZonetime-zonestring | undefinedIANA 时区；缺省取运行环境所在的时区。
readonlyreadonlyboolean | undefined只读：可选择、浏览与预览，不能修改；缺省可修改。attribute 写 "false" 是可修改，其余写法是只读。
modemodeReportDesignerMode | undefineddesign 或 preview，缺省 design。
autoTourauto-tourboolean | undefined第一次铺好画布、设计器显示出来（画布有宽度）后自动开始新手引导，缺省开；设置里记过 help.tourDone（走完、跳过或关上过一次）时不再自动开始。写 false 关掉，start-tour 命令、帮助页的「开始引导」与 startTour() 照样能开始。同名 attribute auto-tour，写 "false" 是关。
closableclosableboolean | undefined在菜单栏最右端显示关闭钮，按下派发 close；缺省不显示。同名 attribute closable，写 "false" 是不显示。
defaultLayout—DesignerLayout | undefined面板布局的缺省：设置里还没有 layout.panels 时用它，「恢复默认布局」也回到它；不给时各面板停在登记的位置，全部显示。面板 id 见 REPORT_DESIGNER_PANELS，另有扩展登记的面板。用户挪了面板、改了显隐或大小，整份布局写进设置的 layout.panels（DESIGNER_SETTING_KEYS.layout）并派发 settings-change。
datasetEditingdataset-editingReportDatasetEditing | undefined缺省 fields。
settings—DesignerSettings | undefined设置的值：扁平的键值，键是「分区 id.条目 id」，如 general.theme；没写的键取条目的缺省值。赋值即生效；用户在设置对话框里改了以后设计器换成新的一份并派发 settings-change。
settingsPolicy—DesignerSettingsPolicy | undefined宿主对设置条目的管控：键是条目键或分区 id，hidden 不显示，locked 只读、说明换成「由所在系统管理」。
settingsStorageKeysettings-storage-keystring | undefined设置存在根所在窗口 localStorage 的哪个键下：给了，连上文档时若没赋 settings 就从这里读，用户改了设置就写回去，标了 secret 的条目不存；读写失败派发 settings-storage-error。不给就不读写。同名 attribute settings-storage-key。
draftKeydraft-keystring | undefined自动保存草稿的键：区分同一页、同一种设计器里的不同报表（宿主写报表 id）；不给时按页面地址区分。设置里开着自动保存时，未保存的修改停手约一秒存成这台浏览器里的草稿；下次装进同一个键的报表、和草稿不一样时问恢复还是丢弃。同名 attribute draft-key。
historyLimithistory-limitnumber | undefined撤销步数上限，缺省 100；在下一次装载（赋 schema）时生效。同名 attribute history-limit。

存取器 ​

属性读写类型说明
extensions可读写readonly ReportDesignerExtension[] | undefined扩展：卡片与视图种类、渲染、属性编辑器、命令、面板与物料都从这里来，内置扩展自动排在最前。赋值时当场合并查重，冲突抛 DesignerExtensionError、什么都不变；各扩展的 setup 在元素连上文档时调用、断开时清理。同一个扩展对象换了引用当作卸下再装上，宿主要保持引用稳定。去掉的扩展登记的种类在报表里原样保留，画布上画占位。
canUndo只读boolean能不能撤销；只读时为 false。
canRedo只读boolean能不能重做；只读时为 false。
dirty只读boolean有未保存的修改。
canPaste只读boolean编辑模型里留着可粘贴的内容。
canDelete只读booleandeleteSelection() 此刻能删掉东西：选中了卡片、列表项或联动，或 datasetEditing 允许删的数据面板对象。
historyState只读HistorySnapshot撤销历史的快照：各步的说明按此刻的语言取好；还没有报表时只有起点。
xhConfig只读XhConfig设计器这棵子树的配置：设置里选了语言时是这一语言的 UI、designer-shell 与报表语言包，跟随页面时是空对象。设计器自己、里面的元素（含预览的查看器与图表）与它弹出的浮层都按它取 locale 与文案，页面别处不受影响。
canImportTemplate只读boolean此刻能不能导入模板：登记了导入器、有报表、在设计态且不是只读。

方法 ​

方法说明
execute(operations: readonly ReportOperation[], options?: ExecuteOptions): ReportDocument执行一组操作并记为一步撤销；返回新文档。还没有报表时抛错。
undo(): boolean撤销一步；只读或没有可撤销的时返回 false。
redo(): boolean重做一步；只读或没有可重做的时返回 false。
goToHistory(position: number): boolean跳到撤销历史里的一步或起点（historyState 里的位置号）；只读、预览、拖动中或位置号不认识时返回 false。
clearHistory(): void清空撤销与重做；报表与是否已保存不变。只读或拖动中时什么都不做。
markSaved(): void把当前位置记为保存点。
addCard(init: ReportAddCardInit, options?: ExecuteOptions): DashboardCard新增卡片并选中它；报表主体不是看板时抛错。
addPaletteItem(id: string): DashboardCard | undefined照点物料的做法新建一张卡片：放到第一个空位、选中它并滚到看得见的地方，返回新卡片；只读、主体不是看板或没有这个物料项时什么都不做，返回 undefined。点物料面板的条目时调它。
select(selection: Partial<ReportSelection>): void换成给出的选择：给了 data 只选数据面板里的对象，否则选 cards，再带 item 或 link 之一。
selectAll(): void选中看板上的全部卡片；主体不是看板时清空选择。
getSelection(): ReportSelection当前的选择。
deleteSelection(): boolean删除选中的对象：卡片、列表项或联动直接删；数据面板里的字段、参数与数据集按 datasetEditing 能删时删，会一并删掉别处时先弹确认框，确认后合为一步撤销。返回是否删除（或已弹出确认框）。
copy(): ReportClipboard | undefined复制选中的卡片，同时写进系统剪贴板；没有选中卡片时返回 undefined。
cut(): ReportClipboard | undefined复制后删除选中的卡片，同时写进系统剪贴板；只读或没有选中卡片时返回 undefined。
paste(clipboard?: ReportClipboard): ReportSelection粘贴卡片，不给 clipboard 时用最近一次复制的内容；返回新的选择。
duplicate(): ReportSelection复制选中的卡片并当场粘贴，不经剪贴板；返回新的选择。
validate(): readonly ValidationIssue[]按当前的表达式引擎校验报表。
refresh(): Promise<void>丢掉缓存的数据，画布重新取数计算。
scrollToCard(id: string): void滚动到卡片。
revealCard(id: string): void卡片不在画布的可见区时才滚动到它。
highlightCard(id: string | null): void在画布上标出一张卡片（画悬停框），null 撤掉；不改选择、不滚动。页面结构面板悬停或聚焦到一行时用它。
canImportData(kind: ReportDataImportKind): boolean这种导入此刻能不能做：只读、预览态或 datasetEditing 不够时不能（导入数据集与字段要 full，导入参数要 fields 起）；导入字段还要在数据面板里选中一个数据集或它的字段。
openDataImport(kind: ReportDataImportKind): boolean打开导入对话框：dataset 从 JSON 样例或 JSON Schema 新建一个数据集，fields 往选中的数据集里加字段，parameters 从 JSON Schema（也可以是样例）加报表参数。对话框里还有扩展登记的字段来源页（fieldSources）。导入的字段只取值字段，同名的保留现有的，一次导入记一步撤销。此刻不能做时返回 false。
startTour(): boolean从头开始新手引导：通用步骤加报表与扩展的步骤；同一页别的设计器的引导开着时先收起那一个。预览态、还没有报表或没有能走的步骤时返回 false。
openJsonEditor(): boolean打开编辑整份报表定义 JSON 的对话框：写出当前报表，边改边按当前扩展与表达式引擎校验、报问题（文字与问题列表的一致）；没有错误时「应用」整份换上，记一步撤销，说明是「编辑 JSON」。只读或预览态时只能看、不能应用。还没有报表时返回 false。
importTemplate(): boolean导入模板：弹出选文件对话框（accept 取各导入器的 fileTypes），选中的文件按扩展顺序交给第一个接下的导入器，给出的整份模板换上当前报表、清空选择，记一步撤销（说明是「导入模板」）。没有导入器接下、导入器抛错或给出的不是报表对象时派发 import-error。此刻不能导入（见 canImportTemplate）时什么都不做，返回 false。
revealItem(ref: ReportItemRef): void选中列表项所在的卡片并让它可见。
getViewport(): Viewport视口：屏幕坐标（画布可见区的左上角为原点）= 画布坐标 × zoom + (x, y)；画布坐标是实际尺寸下画布里的像素，zoom 为 1 时是实际尺寸。画布还没有布局时 x、y 为 0。
setViewport(viewport: Viewport): void设置视口：缩放夹进 10%–400%，平移落在画布能滚到的范围里；此后尺寸变化不再自动适配。
zoomToFit(): void缩放到整块内容的高度落进可见区，宽度总是铺满可见区，不放大到实际尺寸以上；此后画布或内容的尺寸变了就重新适配，直到改了缩放、设置视口或在画布上按下指针。
zoomIn(): void以可见区中心放大一档。
zoomOut(): void以可见区中心缩小一档。
zoomToActual(): void以可见区中心缩放到实际尺寸。
openSettings(section?: string): void打开设置对话框，给了分区 id 就显示那一页：基础是 general，扩展的是它登记的分区 id。

事件 ​

事件都是冒泡的 CustomEvent。

事件detail说明
schema-change{ schema: ReportDocument, operations: readonly ReportOperation[], kind: ReportSchemaChangeKind }报表变了：schema 是新的报表，operations 是这一步的操作，kind 说明是执行、撤销、重做还是装载。
selection-changeReportSelection选择变了，detail 是新的选择。
dirty-change{ dirty: boolean }与保存点相比有没有改动变了。
history-changeHistorySnapshot撤销历史变了：执行（含并入上一步）、撤销、重做、跳转、装载、清空与保存之后都派发，拖动等事务进行中不派发。detail 是此刻的 historyState。
issues-change{ issues: readonly ValidationIssue[] }报表的校验问题变了。
saveRecord<string, never>在画布上按了 Ctrl+S（macOS 上 ⌘S），或点了「文件」菜单的「保存」（命令 save）；保存由宿主做，存好后调 markSaved()。
closeRecord<string, never>按了菜单栏最右端的关闭钮（closable 开着时）。设计器自己不做别的，关掉或回到列表、有未保存的改动时先问，都由宿主做。
mode-change{ mode: ReportDesignerMode }在设计与预览之间切换了。
card-dblclick{ id: string }双击了一张卡片。
card-contextmenu{ id: string, x: number, y: number }可取消；不取消时弹内建右键菜单。
blank-contextmenu{ x: number, y: number }可取消；不取消时弹内建右键菜单。
settings-change{ key: string, value: JsonValue | undefined, settings: DesignerSettings }在设置对话框里改了一条设置，或在外框上挪了面板（键是 layout.panels，值是整份布局）：设计器已换成新的 settings 并生效（主题、主题色、扩展读的值与面板布局）；value 为 undefined 表示删掉这个键、回到缺省值。宿主存起来，下次赋回 settings。
settings-storage-errorVisualEnvironmentStorageError读写 settingsStorageKey 指的本机存储失败（内容不是对象、无痕窗口、配额满）；设置留在内存里。
viewport-change{ viewport: Viewport }视口变了：缩放、适合窗口、setViewport 与滚动画布都会派发。
import-error{ importer?: string, source: DesignerImportSource, error: unknown }导入模板没有成功：导入器抛了错，或给出的不是报表对象，importer 是导入器的 id；选中的文件没有导入器接下时也派发，此时没有 importer。

类型 ​

ReportDesignerMode ​

设计或预览。

ts
type ReportDesignerMode = 'design' | 'preview'

ReportDatasetEditing ​

数据集能改到什么程度：none 只读；fields 能改字段的标题、类型与计算字段公式，增删报表参数；full 另能增删数据集与字段。

ts
type ReportDatasetEditing = 'none' | 'fields' | 'full'

ReportSchemaChangeKind ​

schema-change 的来由。

ts
type ReportSchemaChangeKind = 'execute' | 'undo' | 'redo' | 'load'

REPORT_DESIGNER_PANELS ​

设计器的面板 id：宿主写 defaultLayout、settingsPolicy（layout.panels.<面板 id>）与 commandLayout（panel:<面板 id>）时用。

ts
const REPORT_DESIGNER_PANELS = {
  datasets: 'datasets',
  parameters: 'parameters',
  palette: 'palette',
  wells: 'wells',
  properties: 'properties',
  issues: 'issues',
  history: 'history',
  outline: 'outline',
} as const

ReportSelection ​

选择：看板上的卡片，以及可选的一个列表项或一条以选中卡片为源的联动；或者数据面板里的一个对象，这时不选卡片、列表项与联动。

属性类型说明
cardsreadonly string[]选中的卡片 id。
item?ReportItemRef选中的列表项。
link?string选中的联动 id；它的源卡片也在 cards 里。
data?ReportDataRef数据面板里选中的对象。

ReportItemRef ​

选中的列表项：报表主体或卡片里某个列表的一项（列、分组、维度、度量、系列）。

属性类型说明
card?string所在的卡片；报表主体的列表项不写。
listItemList所在的列表：dimensions、measures、series、rows、columns、groups。
idstring列表项的 id。

ReportDataRef ​

数据面板里选中的对象：数据集、数据集的字段或报表参数。

ts
type ReportDataRef = | { readonly kind: 'dataset', readonly dataset: string } | { readonly kind: 'field', readonly dataset: string, readonly name: string } | { readonly kind: 'parameter', readonly name: string }

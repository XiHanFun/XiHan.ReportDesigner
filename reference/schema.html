报表定义类型 ​

报表定义 ReportDocument 的全部类型，按 @xihan-report/core 的源码列出。当前 schema 版本 REPORT_SCHEMA_VERSION 为 1。

报表定义是纯 JSON：数据集只描述字段与参数，不含数据；数据由取数回调按请求交回。各对象都可以带 extensions，放扩展自己的数据，见扩展数据。「中文名」是设计器属性面板里的叫法，详见属性。

报表与参数 ​

ParameterOption ​

参数的一个候选项。

字段类型必填中文名说明
valueScalarValue是数值取值，类型与参数一致：date 写 YYYY-MM-DD，datetime 写不带时区的 YYYY-MM-DDTHH:mm[:ss]。
labelstring可省—显示的文字；不写按取值显示。
disabledboolean可省—在参数栏里列出但不能选；宿主或缺省值给了这个取值照样认。

ReportParameter ​

报表参数：报表使用者填写，经绑定传给数据集参数或筛选条件。

继承 ReportExtensible 的字段。

字段类型必填中文名说明
namestring是名称参数名，在报表内唯一。
typeFieldType是类型
titlestring可省标题
requiredboolean可省必填必须给值。
multipleboolean可省多选接受多个值。
defaultValueParameterValue可省缺省值缺省值。
optionsreadonly ParameterOption[]可省候选项固定的候选项。

ReportDocument ​

报表文档：纯 JSON。

继承 ReportExtensible 的字段。

字段类型必填中文名说明
schemaVersiontypeof REPORT_SCHEMA_VERSION是—报表定义的版本，写 REPORT_SCHEMA_VERSION。
idstring是—报表身份。
titlestring可省标题
descriptionstring可省说明
parametersreadonly ReportParameter[]可省参数绑定
datasetsreadonly DatasetSchema[]是—报表用到的数据集：只描述字段与参数，数据由取数回调交回。
bodyReportBody是—报表的主体：明细表、分组报表、交叉表、看板，或扩展登记的视图。

数据集与取数 ​

DatasetField ​

数据集里的一个字段。写了 formula 的是计算字段，以同一行的字段与报表参数（$名字）为变量逐行求值，不由使用方提供。

继承 ReportExtensible 的字段。

字段类型必填中文名说明
namestring是名称字段名：数据行里的键，在数据集内唯一；不以 $ 开头。
typeFieldType是类型
titlestring可省标题显示的标题，缺省同 name。
formulastring可省公式计算字段的表达式；求值能力由 ExpressionEngine 提供。

DatasetParameter ​

数据集接受的一个参数：取数时由使用方的数据源解释。

继承 ReportExtensible 的字段。

字段类型必填中文名说明
namestring是名称参数名，在数据集内唯一。
typeFieldType是类型
titlestring可省标题
requiredboolean可省必填取数时必须给值。
multipleboolean可省多选接受多个值。

DatasetSchema ​

报表引用的一个数据集。

继承 ReportExtensible 的字段。

字段类型必填中文名说明
idstring是—数据集身份，在报表内唯一，也是取数请求里的 dataset。
titlestring可省标题
fieldsreadonly DatasetField[]是—数据集的字段。
parametersreadonly DatasetParameter[]可省参数绑定

DatasetQueryDimension ​

取数请求里的一个维度：按 field 分组，写了 bucket 时按日期粒度取键。

字段类型必填中文名说明
idstring是—维度 id：交回的聚合行里以它为键。
fieldstring是字段
bucketDateBucket可省日期粒度

DatasetQueryMeasure ​

取数请求里的一个度量：对 field 做 aggregate；count 不写 field 时数行。

字段类型必填中文名说明
idstring是—度量 id：交回的聚合行里以它为键。
fieldstring可省字段
aggregateAggregateKind是聚合

DatasetQuery ​

视图需要的聚合：使用方可以照此在后端聚合，返回 aggregated 数据。已聚合数据的每行以维度 id 与度量 id 为键。

字段类型必填中文名说明
dimensionsreadonly DatasetQueryDimension[]是—按哪些维度分组。
measuresreadonly DatasetQueryMeasure[]是—每组要算的度量。
rollupsreadonly (readonly string[])[]是—不可累加的度量（avg、distinctCount）要单独给出的汇总分组：每项是一组维度 id，空数组是总计。没有不可累加的度量时为空。

DatasetRequest ​

取数请求：core 按视图与参数取值算出，使用方据此取数。

字段类型必填中文名说明
datasetstring是数据集数据集 id。
parametersParameterValues是参数绑定数据集参数的取值：已按绑定解析，未给值的参数不出现。
filterFilterGroup | null是筛选已代入参数的筛选；引用了计算字段时为 null，由 core 在取回的行上筛选。
sortreadonly RowSortRule[] | null是排序明细视图的排序；聚合视图为 null。
limitnumber | null是行数上限明细视图的行数上限；没有上限为 null。
queryDatasetQuery | null是—视图需要的聚合；明细视图或引用了计算字段时为 null，此时只能返回明细行。

DatasetRows ​

明细行：core 负责计算字段、筛选、分组与聚合。

字段类型必填中文名说明
kind'rows'是—交回明细行。
rowsreadonly DataRow[]是—明细行：以字段名为键；core 在这些行上筛选、聚合与计算。

DatasetRollup ​

一条汇总行：按 dimensions 分组的汇总值，键同已聚合行。

字段类型必填中文名说明
dimensionsreadonly string[]是—分组的维度 id；空数组是总计。
rowDataRow是—这一组的汇总值：以度量 id 为键。

DatasetAggregated ​

已聚合数据：使用方按请求里的 query 在后端聚合并筛选过。rows 以维度 id 与度量 id 为键；不可累加度量的汇总值由 rollups 给出。

字段类型必填中文名说明
kind'aggregated'是—交回按请求聚合好的行。
rowsreadonly DataRow[]是—每组一行：以维度 id 与度量 id 为键。
rollupsreadonly DatasetRollup[]可省—请求的 rollups 里每个分组的汇总行；请求里 rollups 为空时不写。

DatasetData ​

使用方交回的数据。

取其一：DatasetRows、DatasetAggregated。

ExtensionCard ​

扩展登记的卡片：kind 是带点的种类名。取数部分按种类声明的形状写：同图表卡片的 dataset、parameters 与 query，或同表格卡片的 view，或不取数；其余字段归种类自己。

继承 CardBase、Partial<DataBinding> 的字段。

字段类型必填中文名说明
kindReportExtensionKind是—扩展登记的种类名。
queryReportQuery可省—取数形状为 query 的种类：聚合查询。
viewDataView可省—取数形状为 view 的种类：明细表、分组报表或交叉表。
[key: string]unknown是—种类自己的其余字段，由种类的 validate 校验。

DashboardCard ​

取其一：ChartCard、MetricCard、TableCard、ExtensionCard。

继承 ReportExtensible 的字段。

字段类型必填中文名说明
idstring是—联动身份，在看板内唯一。
cardstring是源卡片源卡片 id。
dimensionstring是源维度源卡片上发出取值的维度：图表与指标卡片是查询的维度 id，分组报表是分组 id，交叉表是行或列维度 id，明细表是列 id。
targetsreadonly LinkTarget[]是目标

DateBucket ​

日期粒度：把日期取成分组键。year → 2026，quarter → 2026-Q4，month → 2026-10，week → 2026-W42（ISO 周），day → 2026-10-16，hour → 2026-10-16T08。

取值见常量 DATE_BUCKETS：

取值中文名
year年
quarter季度
month月
week周
day日
hour小时

fit'all' | 'window'可省—只用于纵轴：定义域按全部数据（all，缺省）还是只按缩放窗口里露出的数据（window）算。

# 设计器

`<xh-report-designer>` 可视化编辑报表定义：从物料拖出卡片，把字段拖进卡片，在属性面板里改配置，问题列表随时指出哪里不对。报表存在哪里、谁能改，都由宿主决定。全部属性、方法与事件见[参考 · 设计器](../reference/designer)。

## 界面

外框从上到下是顶栏、工具栏、中间三栏（左边数据集、报表参数与物料，中间画布，右边字段栏与属性）、画布下方的问题列表与最底下的状态栏。`panels` 决定显示哪些部分，空格分隔，不写就全部显示，写空串只留画布；预览态只留工具栏。

| 部分 | 位置 | `panels` 里的名字 | 作用 |
| --- | --- | --- | --- |
| 顶栏 | 最上面 | — | 常用物料的插入钮：柱线图、饼图、指标卡、明细表与交叉表，钮上图标下面写物料名，点一下照点物料的做法新建卡片。`commandLayout` 写 `{ header: [] }` 就没有顶栏 |
| 工具栏 | 顶栏下面 | `toolbar` | 撤销重做；剪切、复制、粘贴、创建副本、删除；缩放；设计与预览；扩展登记的命令；末组是面板、设置与帮助 |
| 数据集 | 左栏上面 | `datasets` | 数据集与字段，下面是新增数据集与新增字段 |
| 报表参数 | 左栏中间 | `parameters` | 报表参数，下面是新增参数；没有参数又不能新增时收起 |
| 物料 | 左栏下面 | `palette` | 图表、指标、表格；拖到看板上或点一下新建卡片 |
| 画布 | 中间 | — | 看板的卡片可以框选、拖动与改大小，落在网格上；可以缩放，见下文「缩放」 |
| 问题 | 画布下方 | `issues` | 校验问题，点一条选中出问题的对象；错误与警告的条数在面板头上，点一下只看或不看这一级 |
| 字段栏 | 右栏上面 | `wells` | 选中卡片（或主体视图）的维度、度量、系列、列与分组，可以拖进字段、拖动换序 |
| 属性 | 右栏下面 | `properties` | 选中对象的属性；选中多张卡片时编辑共同的属性 |
| 状态栏 | 最下面 | `status` | 左边写选中的对象：选中一张卡片是种类与所在的格，选中几张是个数，选中字段、参数等对象是它的种类与名字，没有选中时是数据集数与卡片数；右边写缩放倍数，点一下回到实际大小。设置里可以关掉 |

数据集、报表参数、物料、问题、字段栏与属性是外框里的卡片：面板头写标题，属性卡片的标题下面写正在编辑的对象，「?」里是这块面板的用法。点面板头的「×」收起这块面板；工具栏的「面板」菜单列出这六块，勾选的显示，再勾上就回来。两处都会改写 `panels` 并派发 `panels-change { panels }`，宿主存起来、下次赋回即可。窗口窄时左右两栏收起，从「面板」菜单打开时以抽屉盖在画布上。

工具栏缺省只显示图标，设置里可以换成文字或图标加文字；顶栏的插入钮总是图标在上、物料名在下。按钮的名字与快捷键报给读屏，悬停或键盘聚焦到按钮时提示命令的文字与快捷键；会删掉内容的命令按危险色显示。工具栏放不下时，末尾的按钮收进「更多」。

- 把字段拖到卡片上，数值字段进度量，其余进维度（明细表与分组报表进列，交叉表进行）；加减维度、度量后，图表与指标卡片按查询里现有的项补全必填的引用。
- 报表参数的固定候选项在属性面板里是一张选项表，逐行编辑值、文字与禁用，可以新增、删除与换序，重复的取值标在那一格上。值格跟着参数的类型：`string` 是文本框，`number` 是数字框，`date`、`datetime` 是日期框；`boolean` 固定 `true`、`false` 两行，值格只读，只编辑文字与禁用。
- 删除被别处用着的字段、参数或数据集时，先弹确认框列出会一并删掉的地方，确认后合为一步撤销。
- `datasetEditing` 决定数据集能改到什么程度：`none` 只读；`fields`（缺省）能改字段的标题、类型与计算字段公式，增删报表参数；`full` 另能增删数据集与字段。
- `readonly` 只能选择、浏览与预览，不能修改。attribute 按三态读：没写或写 `"false"` 可修改，空串、`"true"` 与别的写法只读，移除后回到可修改。这是一处行为变化：此前 `readonly="false"` 也算只读，现在是可修改。
- `mode` 写 `preview` 切到预览，用查看器按 `parameters` 显示报表；切换时派发 `mode-change`。

## 快捷键

焦点在画布上时：

| 按键 | 作用 |
| --- | --- |
| Ctrl/⌘ + Z | 撤销 |
| Ctrl/⌘ + Shift + Z、Ctrl/⌘ + Y | 重做 |
| Ctrl/⌘ + C、X、V | 复制、剪切、粘贴，经系统剪贴板，能在两个设计器之间粘贴 |
| Ctrl/⌘ + D | 给选中的卡片创建副本 |
| Delete、Backspace | 删除选中的对象 |
| Ctrl/⌘ + A | 全选看板上的卡片 |
| 方向键 | 把选中的卡片挪一格；加 Shift 改大小 |
| Esc | 取消选择 |
| +（或 =）、- | 放大、缩小一档 |
| 0 | 适合窗口 |
| Ctrl/⌘ + 滚轮 | 以指针为中心缩放 |
| Ctrl/⌘ + S | 派发 `save` |

## 缩放

工具栏的缩放一组是缩小、放大、适合窗口与实际大小，空白处的右键菜单里也有适合窗口，状态栏右边写着缩放倍数，点一下回到实际大小。缩放范围是 10%–400%，每档 1.2 倍，放大、缩小以画布中间为准，Ctrl/⌘ 加滚轮以指针为准。

看板总是铺满画布的宽，缩放改的是卡片与文字的大小：缩小时一屏看到更多行。适合窗口缩到整块看板的高度落进画布，不放大到实际尺寸以上；之后画布或看板的尺寸变了就重新适配，直到改了缩放或在画布上按下指针。拖动卡片、改大小、框选与从物料面板拖进卡片在任何缩放下都落在同样的格子上。

缩放只是看的方式，不进报表定义，也不记到下次打开。`getViewport()` 读当前视口（屏幕坐标 = 画布坐标 × `zoom` + (`x`, `y`)，画布坐标是实际尺寸下的像素），`setViewport()` 设置它；`zoomIn()`、`zoomOut()`、`zoomToFit()`、`zoomToActual()` 与四条命令相同；视口变了（缩放或滚动画布）派发 `viewport-change`。

## 命令与菜单

工具栏与右键菜单里的项都是命令，扩展可以登记新的命令（见[扩展](./extensions)）。`commandLayout` 改写它们的排列：写了某个位置，那里就只显示列出的命令，内置的与扩展的命令 id 可以混排。

- 右键菜单的条目是图标加文字，行尾写快捷键。
- 末组是面板、设置与帮助：面板点开一张菜单，列出能开关的卡片，勾选的显示，开关时与卡片头的「×」一样改写 `panels` 并派发 `panels-change`；设置打开设置对话框，帮助在新窗口打开本站的设计器一页，地址是包入口导出的 `REPORT_DESIGNER_HELP_URL`。
- 卡片上的右键菜单依次是剪切、复制、粘贴、创建副本，删除另成一组；空白处的是粘贴、全选与适合窗口。
- 撤销、重做、剪切、复制、粘贴、创建副本、删除、全选、缩放的四条、设计与预览这几条命令的文字，以及工具栏的名字，是四款设计器共用的文案，在 designer-shell 语言包的 `xh-designer-commands` 一桶里，换语言时随 `mergeXhConfig` 一起换；要改这些文字，在全局配置里覆盖这一桶。报表自己的文案在 `xh-report-designer`。

## 设置

设置是用户偏好，每人每机一份，不随报表定义保存。`openSettings(section?)` 打开设置对话框，左边一个分区一页：

- 「基础」（`general`）：主题（跟随页面、跟随系统、亮色、暗色）、主题色、工具栏按钮的显示方式（图标、文字、图标和文字，缺省只显示图标）与状态栏。工具栏的显示方式只走设置，没有单独的属性。
- 扩展登记的分区，排在后面。分区 id 与 `general` 或别的扩展重名时，给 `extensions` 赋值就抛 `DesignerExtensionError`。

看板的网格是报表布局的一部分（卡片总落在格子上），随报表定义保存，所以报表没有自己的「画布」一页。`datasetEditing` 管的是能改到什么程度，属于权限，仍是设计器的属性。

<<< @/examples/snippets/settings.ts#open

值是扁平的键值，键是「分区 id.条目 id」，如 `general.theme`，没写的键取缺省值。宿主给缺省、锁定条目或读值时用 `@xihan-ui/designer-shell` 导出的 `DESIGNER_SETTING_KEYS`，不手写键。`settings` 赋值即生效；用户在对话框里改了一条，设计器换成新的一份并派发 `settings-change`，宿主存起来、下次赋回。`settingsPolicy` 隐藏或锁定条目，键是条目键或分区 id：`hidden` 不显示，一个分区的条目全藏了就没有这一页；`locked` 只读，说明换成「由所在系统管理」。

<<< @/examples/snippets/settings.ts#host

- **主题只作用于设计器**：主题与主题色写在 `<xh-report-designer>` 自己的 `data-theme`、`data-brand` 上，页面其余部分不变；设置对话框、菜单这些浮层跟着设计器变。主题色的预设由宿主给 `brands`（品牌 id 与色板格子的颜色，可以用 `@xihan-ui/tokens` 的 `BRAND_PRESETS` 与 `BRAND_PRESET_COLORS`）；给了 `registerBrand`（形状同 `@xihan-ui/tokens` 的 `registerBrand`）才许自定义颜色。两样都不给时没有主题色这一项。
- **扩展读设置**：命令、面板与扩展从上下文的 `settings` 读值，各分区没写的条目已经取了缺省值。

独立使用、没有宿主替你存时，给 `settingsStorageKey`：连上文档时若没赋 `settings` 就从根所在窗口的 localStorage 读，用户改了设置就写回去；标了 `secret` 的文本条目（如密钥）不存。读写失败派发 `settings-storage-error`，设置留在内存里。不给就不读写存储。

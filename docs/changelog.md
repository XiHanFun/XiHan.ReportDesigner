# 更新日志

本页记录 `@xihan-report/core`、`@xihan-report/runtime`、`@xihan-report/designer` 各版本使用者能感知的变更，每条标注 **新增 / 修复 / 调整 / 移除**。这几个包总是同一个版本号一起发布；逐包的完整记录见仓库里各包的 `CHANGELOG.md`。

## v1.0.0-rc.1（2026-10-21）

首次发布，以原生 Web Components 交付，不绑定前端框架。报表定义是纯 JSON，按数据集与参数取数后在浏览器里算出明细表、分组报表、交叉表与看板，看板的卡片能联动、表格能下钻，结果能导出 Excel。

- **新增** `@xihan-report/core`：报表定义的结构（数据集与字段、计算字段、报表参数，主体是明细表、分组报表、交叉表或看板与卡片，卡片之间的联动）、校验与问题码、按参数与联动选中算出取数请求、按取回的明细行或汇总行计算视图与卡片（聚合、透视、排序、公式度量）、编辑操作与撤销重做、卡片与视图种类的登记与扩展合并。纯 TypeScript，不依赖 DOM。
- **新增** `@xihan-report/runtime`：`<xh-report-viewer>` 按报表定义与取数回调计算并显示明细表、分组报表、交叉表与看板，带参数栏、卡片联动与表格下钻事件；`export('xlsx')` 把当前的计算结果写成 Excel 工作簿，`@xihan-report/runtime/xlsx` 把视图排成工作表；与 XiHan.UI 内建语言一一对应的界面语言包（`@xihan-report/runtime/locale`），查看器与设计器共用。
- **新增** `@xihan-report/designer`：`<xh-report-designer>` 可视化设计器，包括菜单栏与工具栏、数据集与报表参数面板、物料、看板卡片的拖动与改大小、画布缩放、字段栏、属性面板、问题列表、预览、撤销重做与剪贴板，页面结构与历史记录面板，设置对话框（主题、主题色、语言、布局、工具栏、自动保存与开发者模式），从 JSON 样例或 JSON Schema 导入数据集、字段与参数，按 JSON 编辑整份报表，按 `draftKey` 在本机自动保存的草稿，以及新手引导。卡片与视图种类、渲染、导出器、取数中间件、属性编辑器、命令、面板、物料、物料来源、导入器、菜单栏的菜单与设置分区都能经 `extensions` 登记。

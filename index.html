曦寒报表设计器框架无关的报表设计器

原生 Web Components · 报表定义即 JSON · 明细、分组、交叉表与看板 · 联动下钻 · 导出 Excel

快速开始
介绍
  • 🧩

    框架无关

    以原生 Web Components 交付，Vue、React、Angular 或不用框架的页面都能直接使用；同一页面放多个实例互不影响。

    了解设计原则

  • 📄

    报表定义即数据

    报表是纯 JSON：数据集、参数与主体视图；计算字段与公式度量用受限表达式，不执行任何代码。

    了解报表结构

  • 🔌

    数据由宿主提供

    组件不发网络请求。取数回调拿到算好的请求，交回明细行，或在服务端聚合后交回汇总行。

    了解取数回调

  • 📊

    明细、分组与交叉表

    明细表带格式、排序、冻结列与合计；分组报表按多级分组出组头与小计；交叉表按行列维度透视，出小计与总计。

    了解交叉表

  • 🧭

    看板与联动

    柱线、饼、漏斗、雷达、桑基、热力与层级图，指标卡带对比与迷你图，表格卡片；点一下图表或表格筛选其它卡片，表格的格子可以下钻。

    了解看板

  • 🎨

    可视化设计器与扩展

    物料、字段栏、属性面板、问题列表、撤销重做与预览；按实例传入扩展，登记新的卡片与视图种类、渲染、导出器与面板。

    了解设计器
